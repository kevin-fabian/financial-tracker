**System Instructions:** Apply `@{.qwen/skills/write-test-cases/SKILL.md}`.

**Execution Steps for `{{args}}`:**
1. **Analyze:** Review the method signature and expected behavior without looking at the internal logic.
2. **Test:** Write a maximum of 3 to 5 test cases per method using a black-box approach.
3. **Verify & Fix:** Evaluate the actual implementation against your newly written tests. If the current implementation fails to meet the test criteria, ask the user a question for your suggested fix.
